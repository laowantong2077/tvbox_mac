# 播放器回归验证

安装项目依赖后，在仓库根目录运行：

```sh
node --test tests/player-session.test.cjs tests/player-health.test.cjs
npx tsc --noEmit
npm run build
```

回归测试将真实的播放会话代码编译后，在模拟媒体元素、hls.js 和计时器上运行，覆盖：

- Apple 原生 HLS 的选择与播放引擎切换。
- 网络和解码恢复次数独立、有上限；HTTP 403 与解码错误分别提示。
- 恢复播放进度、倍速、暂停状态与直播可播放窗口。
- 有缓冲但停止输出视频帧时的恢复；正常播放、暂停、拖动和后台不误恢复。
- 音轨与字幕轨选择，以及卸载时取消探测、计时器和旧会话回调。

这些测试不模拟真实的硬件解码器。发布前仍需在 macOS 应用中播放 HLS 测试流，检查视频帧持续更新，并检查重载后的进度、倍速和暂停状态。绿屏或灰屏也可能来自源视频本身，遇到具体视频故障时应使用相同线路复测。
